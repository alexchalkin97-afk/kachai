Политика конфиденциальности приложения «Качай»

Редакция от 24 октября 2026 года

Эта политика описывает, какие данные обрабатывает мобильное приложение «Качай» для Android (пакет app.kachai, далее — «Приложение»), зачем и кому они передаются. Политика составлена в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

2. Главное коротко

  • У Приложения нет собственного сервера. Ссылки, которые вы вставляете, и скачанные файлы хранятся только на вашем телефоне.
  • Видео скачивается напрямую с сайта, ссылку на который вы указали.
  • Данные передаются только сервисам, перечисленным в разделе 4: рекламе и статистике Яндекса и платёжной системе RuStore.
  • Мы не продаём данные и не просим пароли.

3. Данные, которые хранятся только на вашем телефоне

  • Ссылки и история загрузок: название, автор, адрес страницы, обложка и путь к файлу. Нужны для списка «Загрузки». Удаляются из списка в Приложении или вместе с Приложением.
  • Скачанные файлы: сохраняются в папку «Загрузки/Качай» и остаются у вас после удаления Приложения.
  • Настройки: тема, качество по умолчанию, счётчик бесплатных загрузок и статус подписки.
  • Вход во ВКонтакте или Одноклассники (только если вы сами его выполнили). Вход происходит на официальной странице сайта, пароль Приложение не видит и не сохраняет. Сохраняются только файлы сессии (cookie), чтобы скачивать видео, доступные вашему аккаунту. Отвязать аккаунт и удалить эти файлы можно в «Настройки → Аккаунты».
  • Журнал ошибок: технические сообщения о поиске и загрузке (адреса страниц без параметров, тексты ошибок, модель телефона и версия Android), без паролей и cookie, ограничен по размеру. По кнопке «Отправить отчёт» открывается ваше почтовое приложение с готовым письмом разработчику на адрес из раздела 1. Журнал уходит, только если вы сами нажмёте «Отправить» в почте. Письмо хранится в почтовом ящике разработчика и используется только для исправления ошибок.

4. Сторонние сервисы

Сайты, с которых вы скачиваете видео. Приложение обращается к ним напрямую, как браузер. Они получают ваш IP-адрес и сам запрос и обрабатывают их по своим правилам.

Рекламная сеть Яндекса (Yandex Mobile Ads) — только в бесплатной версии. Для показа рекламы SDK может получать рекламный идентификатор устройства, сведения об устройстве и сети, IP-адрес и данные о взаимодействии с рекламой. Обработку выполняет ООО «Яндекс» по своей политике: yandex.ru/legal/confidential. Персонализацию рекламы можно отключить в настройках Android («Конфиденциальность → Реклама»). В подписке «Качай Плюс» реклама не загружается.

AppMetrica (Яндекс) — обезличенная статистика использования: запуски и экраны, сайт источника (например, «Rutube»), выбранное качество, успех или текст ошибки, примерный размер и скорость загрузки, модель устройства и версия Android. Ссылки, названия видео и данные аккаунтов в статистику не передаются, отслеживание местоположения выключено. Политика: yandex.ru/legal/appmetrica_termsofuse.

RuStore (ООО «ВК») — оформление и проверка подписки «Качай Плюс». Платёжные данные вводятся в окне RuStore. Приложение их не получает, а узнаёт только, активна ли подписка и до какой даты. Правила: rustore.ru/help/legal.

GitHub — раз в сутки Приложение скачивает обновление модуля загрузки yt-dlp с github.com. GitHub видит IP-адрес устройства, никакие другие данные не передаются.

5. Сроки хранения и удаление

Данные из раздела 3 хранятся на телефоне, пока вы их не удалите в Приложении или не удалите само Приложение. Данные у сторонних сервисов хранятся по их правилам. Чтобы задать вопрос или отозвать согласие на обработку, напишите на адрес из раздела 1.

6. Дети

Приложение не предназначено для детей младше 12 лет и не собирает намеренно их данные.

7. Авторские права

Приложение — инструмент для скачивания. Используйте только видео, на которые у вас есть права, или в рамках допустимого цитирования.

При изменении политики обновляется дата редакции на этой странице. Существенные изменения мы сообщим в описании обновления Приложения.
