# Качай

Android-приложение для скачивания видео и звука с VK Видео, Rutube, Дзена, Одноклассников
и ещё 1000+ сайтов. Качает через обычное подключение телефона, своих серверов и прокси нет.

## Как устроено

| Часть | Что делает |
|---|---|
| `dl/Engine.kt` | yt-dlp внутри приложения (библиотека youtubedl-android: Python, ffmpeg, QuickJS). Сам обновляется раз в сутки |
| `dl/DownloadService.kt` | Фоновая загрузка с уведомлением, сохранение в «Загрузки/Качай» |
| `dl/LinkResolver.kt` | Приводит ссылки (например, клипы OK) к виду, который понимает yt-dlp |
| `accounts/` | Вход в VK и OK на официальной странице сайта — для видео «только для вошедших» |
| `billing/Premium.kt` | Подписка «Плюс» (активация кодом) и дневной лимит бесплатной версии |
| `billing/RuStoreBilling.kt` | Оплата подписки через RuStore Pay |
| `ads/Ads.kt` | Реклама Яндекса: баннер, полноэкранная, за вознаграждение |

### Бесплатная версия и Плюс — одно приложение

- **Бесплатно:** 3 загрузки в день (`freeDailyLimit`), видео до 720p (`freeMaxHeight`), реклама «+2 загрузки» до 5 раз в день,
  баннер внизу главного экрана и загрузок, полноэкранная реклама после каждой второй загрузки.
- **Плюс** (подписка от 99 ₽ в месяц; `premiumPrice` — подпись цены, пока RuStore не ответил): без лимита, до 4K (если ролик загружен в таком качестве), без рекламы совсем.

## Сборка

Нужны JDK 17 и Android SDK (platform 35). В этой машине они лежат в `D:\Dev\tools`.

```bash
cp secrets.properties.example secrets.properties   # и заполнить
./gradlew assembleDebug
```

APK собираются отдельно под каждую архитектуру (`app/build/outputs/apk/debug/`):
`arm64-v8a` — почти все современные телефоны, `armeabi-v7a` — старые, `x86_64` — эмулятор.

Release-сборка подписывается ключом из `signing.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`).

## Лицензия

GPL-3.0 — потому что внутри youtubedl-android (GPL-3.0).
Приложение можно распространять и монетизировать рекламой и подпиской, но исходный код
должен быть доступен тем, кто получил APK (укажите ссылку в `sourceUrl`).

## Тарифы, промокоды, оценка

- **Тарифы Плюса** — `billing/RuStoreBilling.kt`: подписка на месяц (`rustore.subscriptionId`) и год (`rustore.yearlyId`),
  разовый Плюс на 30 / 365 дней (`rustore.passMonthId`, `rustore.passYearId` — потребляемые товары). Цены берутся из RuStore;
  тарифа без ID или без товара в Консоли на экране нет. Срок разового Плюса считается по датам покупок из RuStore.
- **Промокоды** — `billing/Promo.kt` и `tools/promo/PromoCodes.java`: код подписан закрытым ключом (`promo-key.properties`,
  не в git), приложение проверяет его открытым ключом `promo.publicKey`. Код тестировщика публиковать нельзя — он даёт Плюс навсегда.
- **Оценка в RuStore** — `Review.kt`: окно RuStore после 3 успешных загрузок, один раз; плюс пункт в настройках.
- **AppMetrica**: `engine_update` (updated / up_to_date / github_unreachable / failed) — по доле `github_unreachable`
  решить, нужно ли своё зеркало обновлений yt-dlp; `promo_activated` — номер промокода.

## Заплатки к yt-dlp

- Записи трансляций VK (`vkvideo.ru/live-…`) `LinkResolver` переписывает в `video-…` — yt-dlp адрес `live-` не знает.
- Часть роликов VK падает в yt-dlp на субтитрах без названия (yt-dlp/yt-dlp#16530). После такой ошибки `Engine`
  повторяет запрос с плагином `kachai_vk.py` (`--plugin-dirs`), остальные ролики идут без него.
- Метки отслеживания (`utm_*`, `si`, `share_to`, `igsh`, `fbclid`…) убираются из ссылок (`LinkResolver.clean`).

## Что ещё не сделано

- Оплата подписки вне RuStore: нужен сервер с `/activate` и страница оплаты (ЮKassa и т.п.).
  В debug-сборке есть переключатель Плюса.
- Вход в Instagram для закрытых постов и Reels, требующих аккаунт.
- **Зеркало обновлений yt-dlp** в РФ (Яндекс Диск или Object Storage + GitHub Actions, `version.json`
  и проверка контрольной суммы) — если по событию `engine_update` неудач много (≈20%; при 1–2% не нужно).
- Канал / группа приложения: ссылку вписать в `communityUrl`, она появится в настройках.
