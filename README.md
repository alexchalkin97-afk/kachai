# Качай

Android-приложение для скачивания видео и звука с YouTube, Instagram, VK Видео, TikTok, Rutube
и ещё 1000+ сайтов. Работает в РФ: если у пользователя включён VPN, качаем через него, если нет —
через собственный сервер (VPS за рубежом).

## Как устроено

| Часть | Что делает |
|---|---|
| `dl/Engine.kt` | yt-dlp внутри приложения (библиотека youtubedl-android: Python, ffmpeg, QuickJS). Сам обновляется раз в сутки |
| `net/Tunnel.kt` | Ядро Xray: VLESS + Reality до VPS. Не системный VPN — локальный прокси только для загрузчика |
| `net/Router.kt` | Выбор пути: VPN включён → напрямую, иначе → VPS. Если путь не сработал, пробует другой |
| `net/VpsConfig.kt` | Адрес сервера: вшитый при сборке или свежий с `remoteConfigUrl` |
| `dl/DownloadService.kt` | Фоновая загрузка с уведомлением, сохранение в «Загрузки/Качай» |
| `billing/Premium.kt` | Подписка «Плюс» (активация кодом) и дневной лимит бесплатной версии |
| `ads/Ads.kt` | Реклама Яндекса: баннер, полноэкранная, за вознаграждение |
| `server/install-vps.sh` | Настройка VPS одной командой |

### Бесплатная версия и Плюс — одно приложение

- **Бесплатно:** 3 загрузки в день (`freeDailyLimit`), видео до 720p (`freeMaxHeight`), реклама «+2 загрузки» до 5 раз в день,
  баннер внизу главного экрана и загрузок, полноэкранная реклама после каждой второй загрузки.
- **Плюс** (`premiumPrice`, по умолчанию 249 ₽ в месяц): без лимита, до 4K, без рекламы совсем.

## Сборка

Нужны JDK 17 и Android SDK (platform 35). В этой машине они лежат в `D:\Dev\tools`.

```bash
bash scripts/fetch-libs.sh          # ядро Xray, ~60 МБ (один раз)
cp secrets.properties.example secrets.properties   # и заполнить
./gradlew assembleDebug
```

APK собираются отдельно под каждую архитектуру (`app/build/outputs/apk/debug/`):
`arm64-v8a` — почти все современные телефоны, `armeabi-v7a` — старые, `x86_64` — эмулятор.

Release-сборка подписывается ключом из `signing.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`).

## VPS

1. Арендовать VPS вне РФ (Нидерланды, Финляндия, Германия), 1 ГБ ОЗУ хватит.
   **Главное — трафик:** одно видео 1080p весит 100–500 МБ. Берите тариф с безлимитом или 10+ ТБ.
2. Залить и запустить скрипт:
   ```bash
   scp server/install-vps.sh root@IP:/root/
   ssh root@IP "bash /root/install-vps.sh"
   ```
3. Скопировать напечатанные строки `vps.*` в `secrets.properties` и пересобрать приложение.

Сервер пропускает только сайты с видео (белый список в скрипте), остальной трафик режет — чтобы
ключ из APK нельзя было использовать как бесплатный VPN. Трафик за месяц: `vnstat -m`.

### Смена сервера без обновления приложения

Если IP сервера заблокируют, приложение возьмёт новый адрес из `remoteConfigUrl` — это любой
JSON по HTTPS, доступный из РФ (например, файл в Яндекс Object Storage):

```json
{"servers":[{"host":"1.2.3.4","port":443,"uuid":"…","sni":"www.microsoft.com","publicKey":"…","shortId":"…"}]}
```

Строку в этом формате тоже печатает `install-vps.sh`.

## Лицензия

GPL-3.0 — потому что внутри youtubedl-android (GPL-3.0) и AndroidLibXrayLite (LGPL-3.0).
Приложение можно распространять и монетизировать рекламой и подпиской, но исходный код
должен быть доступен тем, кто получил APK (укажите ссылку в `sourceUrl`).
Код сервера (оплата, коды) в это требование не входит.
